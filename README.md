# GRAVE DANGER — 像素丧尸街机射击

快节奏、可反复游玩的像素风丧尸生存街机游戏。纯 HTML5 Canvas + WebAudio 程序化音效，**零外部资源、零构建步骤**——双击 `index.html` 即玩（`file://` 直接可用）。

## 运行

直接用浏览器打开 `index.html`。推荐 Chrome / Edge / Firefox。

## 操作

| 按键 | 功能 |
| --- | --- |
| `WASD` / 方向键 | 移动 |
| 鼠标 | 瞄准，按住左键射击 |
| `Space` / `Shift` | 冲刺（带无敌帧，可穿冲击波和子弹） |
| `1`–`4` | 切换武器（手枪 / 散弹枪 / 冲锋枪 / 步枪） |
| `Q` / 滚轮 | 循环切换武器 |
| `R` | **瞬间重开**（任意时刻，街机式快速重置） |
| `P` / `Esc` | 暂停 |
| `M` | 静音开关 |

## 核心循环

- **波次生存**：丧尸从地图边缘与墓碑中爬出，一波清完进入短暂间歇，立刻开下一波。第 1 波就有 12 只，压力来得很快。
- **连击倍率**：每次击杀累积连击（2.6 秒内继续击杀维持），倍率最高 x4，所有分数（击杀、宝石、清波奖励、Boss 奖励）都吃倍率。被打断后清零——追分与保命的天然张力。
- **快速重置**：死亡结算约 1.5 秒后进入结算画面，`R` 或点击立即重开。在死亡慢动作期间也可以直接按 `R`。最高分存 localStorage。

## 武器定位（每种都有明确生态位，不是数值高低）

| 武器 | 定位 |
| --- | --- |
| **PISTOL** | 无限弹药、稳定输出。永远可用的保底武器。24 伤害 / 3.5 发每秒（单体 DPS 最低但零消耗）。 |
| **SCATTERGUN** | 7 弹丸扇射 + 超大击退，近距离清群、推开逼近的丧尸。射程短（约 190px）是代价。 |
| **SMG** | 高速持续输出，融化蛮尸和 Boss 的最佳选择。极端吃弹药。 |
| **RIFLE** | 穿透 3 只丧尸的高速弹，专治排队冲锋与远处吐酸者。弹药极少（14 发）。 |

弹药只从掉落补给，弹尽自动切回手枪——手枪永远不会让你陷入无武器可用。

## 丧尸种类

- **Shambler** 慢速基础怪。
- **Runner** 快速低血量（第 2 波起）。
- **Spitter** 保持距离吐酸液弹（第 3 波起）。
- **Brute** 高血量高伤、抗击退，需要持续火力（第 4 波起）。
- **Exploder** 靠近玩家后引信爆炸，会炸伤其它丧尸——可以连锁引爆（第 6 波起）。远程击杀它则不会伤到你。

## 拾取物与升级

每波必定有一名**发光"搬运工"丧尸**掉落补给箱（击杀它需要留意那个青色光晕）。另有小概率掉落：

- **弹药箱** → 所有已解锁弹药武器的弹药 +40%（受升级加成）
- **医疗包** → +30 HP
- **灵魂宝石** → 分数（吃连击倍率）
- **补给箱** → 暂停游戏，从 3 张随机升级卡中选 1 张（可点击或按 `1/2/3`）

12 种升级（各可叠 3–5 级）：伤害、射速、移速、最大生命、冲刺冷却、弹丸穿透、多重弹丸、拾取磁力、弹药增益、击杀回血、尸爆、击退强化。每局重置——强化组合是每局重开的新鲜感来源。

## 墓碑 Boss：THE WARDEN（每 5 波）

Boss 不是靠加血量拖时间，而是**三个阶段、三套行为**：

1. **阶段一（100%–66%）「埋葬的守望者」**：墓碑钉在原地。召唤丧尸、范围砸地冲击波（贴身红圈预警后扩散的环，冲刺可穿过）、钻地潜行到玩家脚下破土再砸。
2. **阶段二（66%–33%）「裂开」**：石身开裂、浮空开始缓慢逼近。新增**冲锋**（红色虚线锁定方向，撞墙后眩晕 1.2 秒并承受 1.5 倍伤害——输出窗口）、**骨弹环形螺旋**。砸地改为双环。
3. **阶段三（33%–0）「灵魂风暴」**：顶部炸碎，悬浮骷髅核心暴走，移速更快。新增**全屏旋转骨弹风暴**、**地底抓握**（多个红圈预警后破土而出的手掌）、**十字骨弹齐射**，并召唤爆炸丧尸。

每次阶段切换：无敌 1.6 秒、白屏闪光、全场震屏、清空场上弹幕、紫字播报。Boss 血条带阶段刻度，击杀后在慢动作中爆出 2 个补给箱 + 医疗包 + 弹药。

Boss 每循环一次（第 5、10、15…波）血量与强度递增，名字变化。

## 打击感（game feel）

受击白闪、击杀顿帧（hitstop）、屏幕震动、枪口闪光与动态光照、弹壳、血液粒子与地面血迹、伤害数字、连击里程碑提示、冲刺残影、低血量心跳与红边、死亡慢动作、Boss 变身白闪。所有音效由 WebAudio 实时合成（无音频文件）。
